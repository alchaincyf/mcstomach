# retro-pixel · 复古像素隐藏款（20%）

25 号新增的**隐藏视觉主题**：毛绒（plush）仍是 80% 常规款，本目录是 20% 复古像素隐藏款。
由 `mcstomach.py assign-visual` 在胃档案**首次**生成时一次性抽签决定（5 个等概率槽位占 1），
结果写入 profile 的 `visual.theme`，**改昵称、重导出、重出图都不重抽**。

## 整卡中文 prompt（分配到 retro_pixel 后整张生图用）

以参考图1为整体配色与布局气质（青绿背景、米黄 CRT 电脑外壳画框、金色像素边框），
参考图2的像素徽章与像素框画风，主角为参考图3咖啡杯小伙伴的**原创像素精灵形态**：
低分辨率像素块拼成的圆胖咖啡杯身体、米白像素杯身、红色像素杯套与背带、胸前金色双拱门贴布、
小豆豆眼、平嘴、短手短脚，材质彻底是像素、完全不保留绒毛。2:3 竖版完整卡，1024×1536 high。
文字白名单（由每个人自己的脱敏事实填充）：「我的麦门胃」「早咖换堡胃」＋金色像素徽章「隐藏款」
「早餐可以换，咖啡要到场」「最近3次早餐」（小太阳＋计数点）「主食3款」（3 个不同抽象主食图标）
「咖啡3/3」（3 只像素咖啡杯各打勾、不画热气）。像素块大小统一，真像素风不是平滑插画；
不画日期、奖品、奖杯、价格、二维码、机器人、排名、百分比；不使用现有游戏角色；
无英文、无免责声明页脚；工具 AI 生成标识保留。

## 分工与验收

- 抽签：`assign-visual`（首次、一次、持久化，标准库随机源，不存种子）
- 生图：图像生成能力整张直出，**不走 HTML 拼接**；出图前先核对白名单文字与三块统计图形
- 表情 L/M/N 由用户挑，与主题稀有度**解耦**
- 没有生图能力时如实降级，**不谎称得到像素图**
- 样卡：项目 `配图/像素隐藏款-v10/早咖换堡胃-像素隐藏款-样卡.png`（设计预览，不是某人抽中结果）
