# reference-J · 按用户参考追加的手绘版（**已定版画风 · I 仍是已选定方向**）

本目录存的**不是** skill 自己生成的样稿，而是**用户在本会话提供的自有项目参考**：
用户拿它说「视觉设计风格可以参考这个再做一个版本」，于是追加出 **J 版式**（CLI 用 `--style J`）。

J **不改动已选定的 I**：`--style I` 仍是默认与推荐；J 只是**同一信息结构换一层外壳**去配手绘插画。

| `style/reference-J/README.md` | 本文件：来源说明、可借的画风要点、明确不借的东西 |

**版权与边界**：参考图**归用户本人所有**，随包只作**画风示例**。
**不得**复用、改写或再分发它里面的**具体角色形象**（包括那只闪电造型本身），
也**不得**把它当成麦当劳相关素材。

## 从参考图里**可以借**的（只借画风与动作语言）

| 项 | 具体借什么 |
|---|---|
| 轮廓 | **粗深灰描边**，线条稳、闭合、不抖 |
| 配色 | **奶油白 / 浅杏**为主的低饱和底色，饱和色只做**小面积点缀** |
| 画法 | **扁平插画**，无写实光影、无体积渐变、无贴图纹理 |
| 五官 | **一对倒 U 弯月笑眼 + 一条小 U 形笑嘴**，脸占主体可见面积的上三分之一 |
| 动作 | **抱住**怀里的东西——「抱着」是这套画风的情绪核心 |
| 留白 | 主体居中，四周留**呼吸白**，不要塞满 |

## **不要借**的（这些是踩过的坑）

- **不复刻参考图里的角色**（树懒、闪电，或任何具体形象）；
- **不上参考图里的文字、标语、吊牌**；
- **不画热气、不画冰块**——温度没确认就不画；
- **不画马克杯把手**：外带纸质咖啡杯**没有把手**，也不是马克杯 / 罐子 / 酸奶杯；
- **脸不能被道具挡住**：抱着的袋子只能到**下半身**，杯身上半部必须完整露出眼睛与嘴。
  （J 首版就是因为袋子盖住脸被判不合格，见 `references/visual-guide.md` §6.5。）

## 与 I 的关系

| | I（已选定） | J（按参考追加） |
|---|---|---|
| 信息结构 | 竖版卡：场景区 + 信息区 | **完全沿用 I**，同一批白名单字段、同一套样本边界 |
| 画风 | 电影级 3D 动画角色的柔软体积 | 扁平手绘：粗轮廓 + 奶油色 + 弯月笑眼 |
| 字体 / 色板 / 边线 | 暖白 + 深可可 + 麦当劳红 | 换成 **#FFFDF8 底 + 2px 深灰边 + 圆体**，去阴影 |
| 渲染实现 | `.cardI` | `.cardJ`（`_card_j` 只把外壳类名换成 `cardI cardJ`，文字一个字不改） |

**两份卡的文字内容必须完全一致**——J 换的是字体、色板与边线，**证据与边界一个字都不许动**。

**卡面高度随内容自然加长**（3 倍导出实测 1080×1716 / 1080×1728），**不是**固定 3:4；
**不要**为了凑比例去裁掉来源范围与邀请语。
