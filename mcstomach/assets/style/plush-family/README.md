## 角色个性配方（22 号 · 别给食物统一装一张脸）

每只角色应有「**餐品识别 ＋ 专属姿态 ＋ 一件有来由的道具 ＋ 微小性格**」，但**不堆满**——一次只突出一件事。

1. **先保结构，再谈个性。** 餐品的识别层次一个都不能少：巨无霸还是三层包双饼，麦香鱼还是鱼排＋塔塔酱；
   个性只体现在**姿态与道具**上，不改变它是什么。
2. **姿态与道具从餐品的特征或名字出发**，不要凭空发明：
   - **麦香鱼 → 抱鱼小伙伴**：鱼堡的「鱼」本来就在它名字里，于是抱一条**天蓝色毛绒小鱼**当玩偶朋友。
     鱼比汉堡小很多，脸、鱼排层和盘前金拱门都清楚可见。**小鱼是造型隐喻**，不是新餐品、不是宠物结论，
     **不画写实死鱼／生鲜鱼肉／刀叉**。
   - **巨无霸 → 壮壮教练**：巨无霸又高又宽，天然有「壮」的气质，于是做**健身教练屈臂举拳**的姿势，
     双臂更饱满但仍软短绒，二头肌是**填充棉小鼓包**，可加一对细黄毛绒护腕。表情依然淡淡的，
     和壮壮的动作形成可爱反差。**没有任何营养／增肌／健身声称，也不据此推断用户的健身或职业**。
3. **避免全员同一坐姿。** 下一只角色先问一句：它有什么专属动作或道具？没有想清楚就先保持通用坐姿。
4. **表情层照旧可选 L / M / N**，个性不改变表情系统；**不能把姿态当成人的人格诊断**，
   更不能从消费数据推「这人爱健身／爱养鱼」。
5. **道具是明确的造型隐喻，不据此生成新的口味规则**，也不新增餐品证据。

通用要求不变：材质 / 圆鼓体积 / 短手脚 / 小五官以 **M-薯条**那张为参照；
**一次生成一张、逐张顺序执行**；`1024x1024` / `high`；右下角保留工具生成标识。

## 四条通用规矩

1. **餐品由真实偏好决定，不由模板决定。** 只按用户**已确认的可分享偏好**选主角；不因人点过堡就默认他会点薯条。
2. **不要自动附加食品。** 画面里出现什么餐品必须有依据——画了堡就顺手塞一包薯条，是把薯条当成了所有人的默认装饰。
3. **表情由用户自选。** 无脸 / 面无表情 / 有点不高兴三支地位平等，**不许**因为「不笑 / 没脸」自动补笑脸。
4. **形状锚点必须放 `image1`。** 薯条 / 堡 / 可乐这类**身体＝餐品本体**的角色，第一位必须给**同餐品的官方餐品图**；
   把「同表情的毛绒锚点」放第一位，出图会被它的身体带跑（薯条曾因此长出咖啡杯身）。
   **`image2` 放材质/比例/五官锚点，默认就用 `M-薯条-发呆也要有薯-毛绒原图.png`**（见上一节的强偏好）；
   `image3` 放官方金拱门（贴布形状依据）。

## 七种餐品的识别特征（必须保留）

| 餐品 | 必须画出来 | 绝不画 |
|---|---|---|
| **咖啡** | 奶油白短绒杯身、红色绒杯套、细黄织带、软绒杯盖 | 马克杯把手、热气（温度没证据就不画）、冰块 |
| **薯条** | **红色绒面薯条盒**＝身体，盒口红绒边，盒中长短错落的**金黄绒条**；脸直接绣红盒上 | 奶油白杯身、白色厚杯口圆环、油亮脆皮的真实油炸薯条 |
| **麦香鱼** | 光滑圆顶面包（无芝麻）、方形鱼排、薄芝士、塔塔酱 | 芝麻、生菜、番茄、肉饼 |
| **巨无霸** | 芝麻圆顶 + **三层绒布面包 + 两块绒布牛肉饼**，中间夹生菜、芝士、腌黄瓜；**高而宽** | 两层面包一层饼的普通堡 |
| **麦辣鸡腿堡** | 芝麻圆顶 + **一块厚且金黄蓬松的炸鸡排**（炸衣用卷曲金黄绒线堆成绒球）+ 生菜与浅色酱；**单鸡排单夹层** | 两层牛肉饼、鱼排、油亮脆皮写实炸物 |
| **板烧鸡腿堡** | **横向椭圆、光滑无芝麻**的面包 + 一片**宽扁、不规则、两侧不对称**的烤鸡腿肉（**比面包更宽、两侧超出轮廓、边缘有自然起伏波浪**，偏浅的烤金棕色绒布，哑光）+ 大片生菜；**横、扁、软** | 规整的圆形厚肉饼、深褐色牛肉饼色、芝麻顶、蓬松炸鸡排、方形鱼排 |
| **可乐** | **高而瘦的曲线杯**（杯口最宽外翻、往下收窄、杯底略外展）；杯口露出**深棕绒做的可乐液面**；**红色绒布杯套 + 金色双拱小贴布**；**一根毛绒软吸管**（红白相间绒线） | 咖啡的厚绒布杯盖、玻璃写实杯、热气、冰块、**任何文字与 Coca-Cola 字样** |

三种汉堡必须**一眼分得开**：巨无霸＝高堆叠双饼、麦辣＝蓬松炸衣绒球、板烧＝横扁光滑包＋**宽扁不规则烤腿**。
可乐必须与咖啡分得开：**没有杯盖**，有**液面与吸管**。

> ⚠️ **板烧的坑（踩过）**：肉只要写成「一片较扁的深棕色肉」，出图就是**规整的深褐圆饼**——和巨无霸的牛肉饼撞脸。
> 必须写足四点：**比面包更宽**（两侧超出轮廓）、**更扁**、**不规则不对称**（一侧宽一侧窄、边缘起伏波浪）、
> **颜色偏浅的烤金棕**（不是深褐牛肉色）。

## 三个表情槽位（可直接复用）

| 槽位 | 面部 |
|---|---|
| **L · 无脸** | 脸所在的那一片绒面**完全干净、连续均匀**，没有眼睛、嘴、鼻、眉毛、腮红、表情符号或任何拟人面部凹痕。**无脸是有意的设计，绝对不要补脸。** |
| **M · 面无表情** | **两颗极小的黑色豆豆眼**平视，**一条极短的水平深棕刺绣线**当嘴，五官居中、间距放松，完全面无表情、呆呆的。没有眉毛、腮红、笑、大眼高光、拟人鼻。 |
| **N · 有点不高兴** | **两颗小小的半睁眼**（深棕刺绣线表现平压眼皮）+ **一条极小、轻微向下弯曲的深棕弧线嘴**。闷闷的但仍可爱；不要凶狠粗眉、怒目、龇牙、眼泪、腮红、笑容。 |

**姿态**：L 软短手自然环抱自身（或轻靠红色绒包装）；M 规规矩矩坐着、小手搭膝/杯套边缘；N 抱臂或抱紧自身、轻轻侧歪。

```
【严厉禁止】不画热气、不画冰块、不画玻璃杯、不出现任何文字/字母/品牌字样（尤其不要 Coca-Cola 字样）。
```

**⑦ 咖啡**：配方见 `assets/style/plush-expressions/README.md`（奶油白短绒杯身 + 红杯套 + 细黄织带 + 厚绒杯盖）。

## 修正口径

**只有**这四种情况才修一轮（每张最多 1 次）：**违背指定表情、肢体变形、品牌图形严重畸形、材质跑偏**
（例：把绒条画成真实油炸薯条、把软吸管画成硬塑料条纹管、把薯条盒画成咖啡杯身）。
**无脸不是失败**，不笑也不是失败——不许因此重做。
