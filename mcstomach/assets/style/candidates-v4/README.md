## ⚠️ 关于「Pixar / 皮克斯」这四个字

**Pixar（皮克斯）在这里只是一个审美参考的说法**——指「电影级三维动画角色的表演、眼神与布光」这类观感。

- 这是**原创角色**，**没有复制**任何现成电影人物，与 Pixar **没有任何关系**；
- **不是官方联名、不是授权合作、不是授权素材**，不得用于任何暗示合作或背书的场景；
- 对外描述建议写「电影级 3D 动画角色风格」，不要写成「皮克斯联名 / 皮克斯授权」。

同样，**麦当劳**这边也只是产品语境：角色是**原创**动画角色，不是麦当劳官方形象或官方周边。
金拱门只用 `assets/brand/麦当劳官网标志.png` **原图**合成，不让生图模型画 logo。

## 三条使用规矩

1. **I 已选定，G/H 未选**：**I** 可作默认方向（`--style I`）；**G/H 不要**写成默认皮肤或默认提示词，
   保留供对照即可。
2. **虚构样张**：三个角色都是**虚构美术样稿**，不代表任何人的真实口味或个人画像，
   不带订单/频率/胃名，也**不能**据此编造「同单搭配」证据。
   展示时标「原创角色风格样稿」；**G/H 另需注明「未选定」**。
3. **只作风格参考**：样张本身不是成品素材，不要直接拼进正式分享卡冒充某个人的专属角色；
   正式出卡时按该用户的真实偏好另起重绘（见 `references/visual-guide.md` §8）。
