# I · 被这一口治愈（**已选定**）

**2026-09-28 花叔选定**，原话：「i这个方向还不错，可以继续推进」（见项目根 `direction-approved.md`）。
保留：圆润坐姿、抱住心爱的那一口、满足微笑、柔软食物质感、电影柔光。
这是**通用美术方向**，不是某一份餐品的专属皮肤——`CLI` 用 `--style I` 调用。

> ⚠️ **虚构角色不作用户默认。** 本目录三张图都是**为虚构样例示范而生**，
> **不代表花叔，也不代表任何真实用户**；更**不能**把「鱼堡 / 咖啡 / 早餐」当成所有人的默认主体。
> 正式出卡时，按**该用户已确认的可分享偏好**另起重绘（见 `references/visual-guide.md` §8）。

## 风格定义

| 项 | 值 |
|---|---|
| 通用风格名 | **被这一口治愈** |
| 主体 | 一份**官方餐品**的圆润拟人小角色（圆鼓鼓的小身体、小手小脚、坐下抱餐品） |

## 通用中文提示词（把 `{}` 槽位按**这个人真实、已确认的偏好**填）

```
Q版电影级3D动画风格的原创拟人小角色，主体是一份【{主食/主餐}】。
造型严格参照官方餐品图：不要画成尖顶包子（鱼堡要有圆顶面包、酥脆鱼排、
塔塔酱、半融芝士的层）。圆鼓鼓的小身体坐着，小短腿自然朝前，
双手抱住【{饮料}】当道具。大而柔和的棕色眼睛、满足的小微笑、脸颊淡粉，
眉毛要极短、极淡、柔和的浅棕色，几乎看不出来，绝对不要粗黑眉毛。
材质是柔软哑光的黏土/毛绒质感，保留食物质感。背景柔和淡桃粉渐变，
【{环境/光线}】。主体与四肢完整居中不被裁切，1024方图，
画面内不出现文字、字母、数字、标志或 logo。
```

**空槽配方**（没有依据的槽位整句删掉，不要硬凑）：

| 槽位 | 取值来源 | 没有依据时 |
|---|---|---|
| `{主食/主餐}` | 出现笔数最高的 `staple` 或 `combo` 餐品 | 用**本次观察里真实出现**的那一口；**都没有 → 不出图，出文字卡** |
| `{饮料}` | 出现笔数最高的 `drink`（**保留冰/热、无糖/含糖，别合并**） | 删掉「双手抱住…道具」这句 |
| `{环境/光线}` | `segment_freq` 里真的有 ≥3 笔的时段 | 用中性柔和室内光；**不要**默认清晨 |

**硬禁忌**（每次自查）：

- ❌ 粗黑眉、歪嘴、半死不活的半睁眼、写实人嘴和牙齿
- ❌ 画面里出现文字 / 数字 / 假 logo / 假认证章
- ❌ 把料想中的「热气 / 冰块」画上去——**温度没确认就不画**
- ❌ 把官方餐品图直接拼进成品冒充插画
- ❌ 把原始订单、姓名、地址、Token 放进提示词
