## 麦当劳识别（用户明确追加的口径）

用户要求「加一些麦当劳的视觉特点」，因此**允许**在道具上出现官方视觉：

- **红色绒布早餐袋正面**缝上**金色双拱**，**保持其双拱形状、比例与颜色**，只把材质转成**织物贴布**；
- 杯身用**红 + 黄**包装色收口，让整体一眼有麦当劳红黄包装的感觉。

边界（**这条不能松**）：

- 画面里**不出现品牌文字或吊牌**；品牌识别**只靠红黄色 + 双拱图形本身**；
- **不暗示**官方周边、联名、授权或背书——它是**原创玩偶的画风探索**；
- **不增加**薯条、汉堡之类的餐品来「凑」品牌感，也**不据此**推断任何人的真实偏好。
