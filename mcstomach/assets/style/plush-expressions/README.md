# plush-expressions · 毛绒三种表情（**三支均已获准继续深化**）

同一只毛绒咖啡小伙伴的**三种面部方案**：**无脸 / 面无表情 / 有点不高兴**。
这三张同时是**毛绒家族**的咖啡锚点——薯条与麦香鱼的对应表情见 `assets/style/plush-family/`。

**状态**：三支**均已获准继续深化**，**不再有待选的「三选一」**；**但没接 CLI**（`STYLE_IDS` 没有新 ID），
**也不预设单一默认**——三支地位平等，谁上台由用户挑。
**不改动已选定的 I**（`assets/style/approved-I/`），也**不改现有 CLI 与渲染逻辑**。
母题画风见 `assets/style/candidate-K/`（毛绒玩具风，同样未接 CLI）。

## 三张的共用配方

- **底图**：既有毛绒样图（`candidate-K/`）为主底图，**保持**奶油白短绒杯身、厚绒布杯盖、
  红色杯套 + 细金黄织带、抱红绒早餐袋的坐姿、短手短脚；
- **杯形比例**：另取一张圆润杯形角色图参考；
- **金拱门**：早餐袋上的金色双拱贴布**严格照官方 logo 的形状与比例**，不变形；
- **唯一变量是脸**：构图、机位、背景、光照、姿态、留白**全部保持不变**；
- **不要**：文字、品牌吊牌、热气、冰块、额外食物、3D 大眼、人类牙齿、腮红、拟人鼻。

**一次生成一张、顺序执行、各存独立目录**，不要一次串多张（容易互相串味）。

## 三个表情槽位规则（可直接复用）

除下面这段，其余提示词**完全共用**：

| 槽位 | 追加内容 |
|---|---|
| **L · 无脸** | 杯身上半部是完整干净、连续均匀的奶油白毛绒表面，**完全没有眼睛、嘴、鼻、眉毛、腮红、表情符号或任何拟人脸部凹痕**。双手仍自然抱紧袋子，靠抱抱动作表达陪伴。**无脸是有意的设计，绝对不要补脸、不要加任何五官。** |
| **M · 面无表情** | **两颗极小的黑色豆豆眼平视前方**，**一条极短的水平深棕刺绣线**当作嘴，五官居中且间距放松，完全面无表情、呆呆的、钝钝的。没有眉毛、没有腮红、没有笑容、没有嘴角上扬、没有大眼高光、没有拟人鼻。 |
| **N · 有点不高兴** | **两颗小小的半睁眼**，用**简短的深棕刺绣线**在上眼位置表现**平压的眼皮**；**一条极小、轻微向下弯曲的深棕弧线嘴**。整体有一点点不高兴、闷闷的，但仍可爱。**不要**凶狠粗眉、怒目、龇牙、哭泣、眼泪、明显的人脸皱纹、腮红、大笑、拟人鼻子。 |

## 一条必须守住的口径

**无脸不是失败。** 曾经把「没画眼睛」当成生成失败的信号，这个判断已被推翻：
**L 的无脸是主动设计**，出图后**不得**因为「不笑 / 没有脸」而自动补一张笑脸。
**这条已由用户确认**：「无脸 / 面无表情 / 有点不高兴」**三个方向都可以继续推进**，
所以**三支都保留**，**不删、不合并、也不指定哪一支当默认**。

**只有**这四种情况才修一轮：**违背指定表情、肢体变形、品牌图形严重畸形、材质跑偏。**
（材质跑偏的例子见「薯条」：薯条必须是**金黄短绒布做的绒条**，不能画成油亮的真实油炸薯条。）
