## 色板

| 用途 | 色 |
|---|---|
| 背景 | 纯净冰蓝（近 `#BBD9EE`）或近白 |
| 主体 | 食物本色（面包暖棕、鱼排金黄、咖啡深褐） |
| 包装局部 | 红黄（杯身印刷标签等） |
| 高光 | 软塑料白高光 |

## 材质与手法

- **搪胶（vinyl toy）质感**：柔光影棚光，表面有软塑料的**高光带**，不是塑料光泽到底；
- 体块**圆润**，只有很轻的环境投影；
- 肢体比例**意外但自然**（例如芝士角成了「短裤」）；
- 表情**小而准**（半睁眼、略疲惫 / 慵懒），不做夸张大笑；
- 明确**避开**：普通写实食品摄影、全身泥土色、旧版 2D 黑描边。
