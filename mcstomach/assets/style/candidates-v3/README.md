## 三条使用规矩

1. **已否决，不要再选**：D/E/F 均未采用，**不要**把它们写成默认皮肤或默认提示词，
   也不要再基于它们继续微调——后续方向见 `../candidates-v4/`。
2. **虚构样张**：这 6 个角色是**虚构演示**，不代表任何人的真实口味，
   也**不能**据此编造「同单搭配」证据。展示时必须标「虚构角色样张」。
3. **只作风格参考**：样张本身不是成品素材，不要直接拼进正式分享卡冒充某个人的专属角色；
   正式出卡时按该用户的真实偏好另起重绘（见 `references/visual-guide.md` §8）。
