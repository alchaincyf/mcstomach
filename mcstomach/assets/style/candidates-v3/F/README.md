## 材质与手法

- **手绘丝网印刷**：炭黑**粗**线，色块之间轻微**套版错位**；
- **半调网点**与颗粒感明确，但**雪白不发黄**（不是复古做旧纸）；
- 造型「歪一点、欠一点」——比例与对称刻意不完美；
- 表情**怪趣**（皱眉为难 / 挑眉坏笑），**不是**幼儿园萌宠的圆点眼微笑；
- 明确**避开**：仅在 D 上加一层噪点充数。
