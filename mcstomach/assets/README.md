# assets · 参考资产与来源清单

本目录随 skill 一起走，用**相对路径**引用，不依赖任何人的本机项目目录。

分成两类，用途不同，别混用：

| 目录 | 是什么 | 能不能直接用在成品里 |
|---|---|---|
| `brand/` | **官方**品牌与餐品参考图 | 标志可作品牌语境标记（不改形）；餐品图**只能当造型参考**，不要直接贴进成品卡 |
| `style/approved-I/` | **已选定**美术方向 I「被这一口治愈」的锚点图与样例 | 作**风格参考**复现 I；样例本身**不是**任何人的专属角色，**不作用户默认** |
| `style/reference-J/` | **用户自有项目**的手绘参考图（不是本 skill 的产出） | 只作**画风示例**；**不得**复用其具体角色形象，也不得当成麦当劳相关素材 |
| `style/candidate-K/` | **候选**画风样图（毛绒玩具风，出过一张） | **未选定、没接 CLI**，只作画风参考；不得说成已接入出卡 |
| `style/plush-expressions/` | 毛绒**咖啡**三表情锚点（无脸 / 面无表情 / 有点不高兴） | **三支均已获准继续深化**，但**没接 CLI**、**不预设单一默认**；只作画风参考 |
| `style/plush-family/` | 毛绒家族 **20 张**（18 张基础 ＋ 2 张个性深化：`M-麦香鱼-抱鱼小伙伴`、`M-巨无霸-壮壮教练`） | **原创视觉演示、没接 CLI**；只作画风参考。两只 M 优先用深化版，旧版仅历史 |
| `style/`（其余） | **原创**卡通风格参考（WorkBuddy 生图产出，保留官方生成标识） | 旧 A/B/C、第二轮 D/E/F **均未采用**；`style/candidates-v4/` 里 **G/H 未选**，**I 已选定**（另见 `style/approved-I/`）。都不要当成默认风格 |
| `templates/` | 可编辑的卡片排版模板 | 可以直接改文字用；中文与数字靠它来排，别让生图模型写中文 |

## 使用规矩（写代码/写提示词时都要守）

1. **给生图工具的只有已确认且可分享的偏好与聚合事实**；姓名、地址、Token、原始订单一律不给。
2. **金拱门只用 `brand/麦当劳官网标志.png` 原图合成**，不让生图模型画 logo（必走形）。
3. **没有依据的餐品不抢主视觉**；麦当劳元素可以来自包装、餐盘、纸袋、红黄配色、门店环境，不是每个人都堆薯条。
4. **餐品图是造型参考，不是贴纸**；不要把官方餐品图直接拼进成品卡冒充插画。
5. **场景里的餐品只是氛围装饰，不构成口味偏好证据。**
